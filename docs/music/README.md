# Music workflow

Use the reviewed [score](../../.agents/skills/score-to-musicxml/SKILL.md) and
[research/arrangement](../../.agents/skills/song-arrangement-research/SKILL.md)
skills. Preserve their review and musical-invariant checks.

Sources, MusicXML, song-specific builders, research, arrangement plans, MIDI,
render settings and listening records all belong under configured `data_root`.
Reusable instructions/code and their schemas stay in Git. Read the
[artifact contracts](../artifact-contracts.md) for lineage requirements and the
[adoption record](../skill-adoption.md) for supported execution and open gaps.
The [ledger plan](../artifact-ledger-plan.md) is not yet implemented.
